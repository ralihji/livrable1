# hiker – Gestion des randonneurs (sous-domaine de support)

Les membres du club qui utilisent le système.

- Profil : courriel (identifiant unique), nom(s), téléphone, adresse, date de naissance, personne-ressource en cas d'urgence, niveau d'habileté.
- Adhésion : ACTIVE, EXPIRÉE ou SUSPENDUE.
- Un randonneur devient organisateur quand un administrateur enregistre sa certification de chef de randonnée (numéro, dates de délivrance et d'expiration) et son niveau d'organisateur.
- Enregistrement avec un code d'invitation à usage unique et une décharge (acceptée par un tuteur légal si le randonneur a moins de 18 ans).
