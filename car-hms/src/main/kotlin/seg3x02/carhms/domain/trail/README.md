# trail – Sentiers de la CCN (sous-domaine générique)

Le club ne tient pas d'informations sur les sentiers : elles viennent des données ouvertes de la CCN.
Ce paquetage traduit ces données (nom, type, surface, difficulté, saison d'ouverture, secteur, zone, stationnement, point de départ) vers le modèle du club, derrière une couche anti-corruption, et en garde une copie locale pour fonctionner si la CCN est indisponible.
